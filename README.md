## Selected production work

### BliQ Messaging Platform

Enterprise multi-tenant communications platform supporting SMS, WhatsApp, VoIP, real-time chat, broadcast campaigns, contact synchronization, billing and usage management.

**My work:** Full-stack/backend engineering across messaging workflows, authentication, billing, Google Contacts synchronization, WebSocket events, broadcast processing and VoIP configuration.

**Engineering focus:** Queue-based processing, batching and database-query optimization for large-volume messaging workflows.

**Stack:** Java, Spring Boot, React, MySQL, MongoDB, Redis, RabbitMQ, WebSockets, Docker, REST APIs, Microservices.

### Techflu — Tech Rental Platform

B2B and B2C technology rental platform with inventory reservations, bookings, recurring payments, KYC, order management and delivery workflows.

**My work:** Developed backend/full-stack features for inventory, bookings, Razorpay AutoPay, order processing, KYC approvals, delivery operations, discounts and promo-code workflows.

**Engineering focus:** Reliable inventory reservation and asynchronous order-processing workflows using Redis, BullMQ and scheduled jobs.

**Stack:** NestJS, Next.js, PostgreSQL, Redis, BullMQ, Docker, Razorpay, Amazon S3 and Digio.

### Reusable Multi-Tenant Identity Platform

Reusable identity provider supporting JWT authentication, OTP login, Google OAuth, role-based access control and tenant isolation.

**Stack:** Java, Spring Boot, PostgreSQL, React, JWT, OAuth, RBAC and REST APIs.
